## Fixed today (23 Oct) — each verified with measurements
1. **LiDAR merger offsets** were 0.7 / −0.7 / −π but the merger adds them ON TOP of TF.
   Front scan was drawn 0.7 m too far forward, rear scan flipped forward → scattered map.
   Now all 0. Merged scan matches walls (6.01/5.99 m ahead/behind, 4.00 m sides).
2. **Two publishers of odom→base_link** (diff_drive enable_odom_tf: true + EKF).
   Now enable_odom_tf: false; only the EKF publishes it.
3. **Casters floated 5 cm above the floor**; robot tipped back and dragged the chassis.
   Now frictionless spheres touching the floor. Pitch 0, no sliding in spins.
4. **Wheel cylinder contact on inner rim** → effective track 0.72 m, robot turned 11% more
   than odometry said. Wheel collisions are now spheres. Odometry = truth (spin −1.5330 vs
   −1.5330 rad; 2 m line 1.9621 vs 1.9621 m).
5. **EKF ignored the IMU** (fused absolute wheel x/y/yaw). Now fuses wheel vx, vy, vyaw +
   IMU vyaw. With an injected 11% wheel fault, EKF turn error 9.9% → 0.3%.
   Healthy wheels: spin 0.4%, line 0.3%, standstill drift 0.008 rad / 120 s.
6. **Stale install copy of ekf.yaml** blocked colcon symlink install (EKF edits were not
   being picked up). Removed; now a symlink.
7. World name `empty` documented, merger config file + launch, worlds/ install rule.
